## 2. 跨域甩击的完整证据链（阻塞记录）

1. **触地前 100ms 姿态是好的**：策略低空帧跟下沉就绪度 0.864-0.868（参考 0.72-0.79）——超过人类参考。
2. **触地瞬间翻转**：pre-TD(5帧) 跟低于趾 8-14°（背屈）→ at-edge +10° 跖屈（趾先）。
3. **翻转只发生在 MuJoCo**：Isaac 域内落足被 heel 斜坡评为 0.87-0.89/事件（近平/微跟先）；ankle_pitch 速率罚在 Isaac 全程 -0.0002（甩击速率 95-110°/s 在域内不存在）。
4. **奖励无法触及**：事件奖励在翻转后采样（r1-r3）；速率罚的域内定义域为空（r4）；稠密先验的低空窗域内仅 ~1 帧（r5）。
5. 参考对照：0002/0000 以 -1.5° 近平跟擦地到达；0005 拖脚 +6°。
6. 根因推测：MuJoCo PD-200Hz 保持目标 vs Isaac 隐式 PD 每步重算的执行差，在触地前的高增益踝通道放大为跖屈瞬态（v25 已知域差异的末端表现）。

**结论**：H1（跟先≥60%）为 sim2sim 域差异阻塞，非奖励设计缺陷。域内已达成跟先就绪（0.87 事件分 + 0.864 姿态分）。解除路径需域侧对齐（MuJoCo PD 重算频率/踝增益标定），超出奖励工程范围。
