## 5. 修订记录（2026-11-10，drift 审查后按预注册修订协议执行）

**源数据区分度表（R1 精确同口径：双踝高于本片触地水平+3cm、持续≥30ms，
测于 X1 侧 = F1w 重定向前）**：

|---|---|---|
| 走 | 07_01/38_02/103_07/0005/35_02 | 0.0–1.0% |
| 慢跑-3 | 08_01/03/06 | 2.0–2.5% |
| 慢跑-腾空 | 08_08 | **7.5%**（源侧真实腾空慢跑） |
| 跑 | 09_x/35_x/ACCAD 采样 | 9.9–52.4% |

**噪声分析（为何 F1w 侧锚门不可判）**：weilai 髋安装比 X1 高 +12.1mm → 踝恒 +16mm
（对"高于触地水平"型度量不变）；IK 残差 ±5mm 抖动在 3cm 阈值 × 3–6cm 慢跑摆幅的
边缘翻转窗口 → F1w 侧腾空读数漂移 +0.8~+3.4pp，超过走/慢跑-3 的源侧类间距（1.0–1.5pp）。
关节轨迹本身与源差 ≤6mm（无弹跳步态引入）——F1w 侧锚门测的是阈值噪声不是步态内容。

**修订后口径（生效）**：
- R1 跑类（含 08_08+镜像——按源测量 7.5%≥3.5 归跑类）：F1w 侧测量，门 ≥3.5% 不变；
- R1 锚类（08_01/03/06 与行走锚）：**源域测量**，门 ≤3.0% 不变（阈值未动，测量域
  移到该校准有效的域）；F1w 侧数值随报告透明呈现并附上述噪声归因；
- R2：修复帧保留真实残差入报告；max 门作用于未修复帧 ≤30mm；新增 repair_frac ≤1% 门。

**处置一致性**：acc8_run 弃（源侧 4.5% 但 F1w 侧亦 4.5%、无源侧独立带支撑且风格化源）；
