## 1. 现状诊断（2026-09-21 实测）

**测量口径**：步态周期 = 同足连续触地间隔（policy 侧：Schmitt 分段，与
gait_metrics.py G2 同路径；参考侧：FK + 髋 L-R 差分自相关双口径，因参考 FK
接触分段存在中途弹跳拆分，参考周期以髋振荡口径为准）。步幅 = 同足连续触地
世界坐标距离。总步频 = 120 / 周期。

| 侧 | 场景 | 周期 s | 总步频 spm | 步幅 m |
|---|---|---|---|---|
| **参考（重定向人类，x1_lab）** | 0000_treadmill_norm | 1.142-1.158 | ~104 | (跑步机无世界位移) |
| | 0002_treadmill_slow | 1.475-1.49 | ~81 | — |
| | 0005/0007/0008 normal_walk | 1.08-1.21 | 99-110 | — |
| | 0026_circle_walk @1.2 m/s | 1.24 | 97 | 0.99 |
| | 36_01 @1.0 m/s（overground） | ~1.03 | ~117 | 0.94 |
| | 36_11 @0.43 m/s（overground） | 1.63-1.83 | 65-74 | 0.53-0.73 |
| 人类文献（1.0 m/s 舒适走） | — | 1.00-1.15 | 105-120 | 1.0-1.1 |
| **策略 m9500@100Hz** | walk10 | **0.396** | **~303** | **0.456** |
| 策略 soup59c_50@50Hz | walk10 | 0.546 | ~220 | 0.53 |
| 策略 m9500@100Hz | walk05 | （0 事件——拖步族） | — | — |

**结论**：当前策略步频为人类 2.1-2.7 倍、步幅约为人类一半。乘积=速度（速度
跟踪已达标），故这是一个自由度上偏——没有任何梯度把它拉回人类节奏。

**根因**（结构性）：
1. **判别器时窗盲区**：disc 观测窗 60ms（3 步 @50Hz），对 1s 级周期失明——
   策略微步在窗内与人类慢动作局部统计不可分。与 v32-v38"判别器观测盲区是
   style-形式背离根因"同型，但这次盲的是时间维度。
2. **正则项中性**：joint_vel_l2 在固定速度下对频率×幅度乘积不变（v ∝ f·A
   抵消）；joint_acc_l2/energy 权重过小不足以压频。
3. **学习动力学**：高频碎步是平衡上更容易的局部解，一旦收敛无梯度离开。

## 3. 训练杠杆设计（v63 单变量）

**gait_period_prior（节奏先验，唯一新变量）**：
- 机制：每足触地上升沿事件奖励 `exp(-|Δt_td − T*(v)| / σ)`，σ=0.25s。
- 速度条件化目标：`T*(v) = clamp(1.46 − 0.36·v, 0.70, 1.75)` s（参考点
  (0.5,~1.35)、(1.0,1.10)、(1.2,~1.03) 与文献的折中回归）。
- 剂量：w 起步 0.6（env 杠杆 `X1_CADENCE_PRIOR`；计划 3 点剂量曲线
  0.3/0.6/1.0，v52-54 方法论）。
- 数值定标：目标行为下事件率 2/T* ≈ 1.8/s，r/step ≈ 0.036·w；当前 0.4s
  周期行为信用 0.09 → 事件率×信用在 T* 单调占优（0.45 vs 1.82 @w=1），
  梯度方向唯一。exp 核全域有梯度（v57 r1 零分桶教训：无桶、无死区）。
- 基座：v59c m9500（50Hz 血统，100Hz 直驱 13/14 的父检查点）@50Hz 微调
  +1000 iters（行为改变幅度大，600 可能不足；中途检查点落盘）。
- **训练在 50Hz**：v61 六轮证伪 100Hz 微调（disc 均衡饱和主动奖励微步）；
  50Hz 直驱 100Hz 已验证保真（m9500@100Hz 13/14）。

**备选路线（v63 失败时）**：
- v64：disc 时窗扩展（AMP_NUM_STEPS 3→12-25，让判别器直接看见节奏）——
  沿 v38"扩展判别器观测"成功路径，但需 disc 重初始化+双侧采样镜像。
