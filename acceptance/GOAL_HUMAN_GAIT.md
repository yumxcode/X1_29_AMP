## 1. 目标一：直膝（Straight-Knee Stance）

**人类特征**：站立中期膝接近全伸（人类 mid-stance 膝屈 5-15°）， stance 期呈现"全伸↔深屈"大摆幅节律（约 0°→60°）。

**实测基线**（`acceptance/diag_knee.py`，膝角约定：0=全伸，正=屈曲）：

| 来源 | stance 中期膝屈 | stance 最直 | 摆动峰值 |
|---|---|---|---|
| 参考数据集 walk 系（0000/0002/0005/0007/0008） | **0.7-6°** | **0.1-2°** | 37-63° |
| v53 策略 walk10 | 36.5/35.7° | 30.0° | 61-65° |
| v54 策略 walk10 | 39.8/37.2° | 32.2-33.2° | — |
| soup534_40 walk10 / walk05 | 36.9-37.0 / 28.9-30.4° | 24.3-31.8° | — |

（v54 后补测：三个候选基座在直膝维度无本质差异——全部蹲在 stance 中期 27-40°，门限不需要因换基座调整。）

**诊断结论**：
1. **数据层无责**——重定向参考已完整保留人类直膝（0.7-6°，教科书区间）。不需要重做重定向。
2. **策略全程深蹲**——膝屈锁死在 30-40° 区间小幅振荡（波动 ~6°），无节律。
3. **根因一**：`DEFAULT_Q` 膝 = 0.632 rad = 36.2° 蹲位（`sim2sim/mujoco_rollout.py`）；动作输出 `q_target = default + 0.25·a`，伸直需要持续负偏置，无梯度推它过去。
4. **根因二**：蹲姿是动力学舒适解（降 CoM、避奇异、PD kp=150 稳定）；joint_vel/acc/energy/torque 正则的合力偏向蹲。判别器对"蹲 36° vs 直"是弱特征（demo 里直膝 walk 与微屈 jog 混合，蹲姿落在分布内）。
5. 摆动峰值 65° 证明膝动力学完全能动——缺的只是 stance 侧的伸直引导。

## 2. 目标二：Heel-Toe 滚动步态

**人类特征**：heel-strike（跟先着地）→ foot-flat（全掌支撑）→ heel-off → toe-off（蹬离）四相滚动。

**实测基线**（`acceptance/diag_heeltoe.py`，FK 重建逐支撑期分类；脚部几何：每足 2 趾+2 跟共 4 球点接触，脚板 14cm）：

| 片段 | 跟先着地 | 趾先 | 全掌支撑占比 | 踝扫 |
|---|---|---|---|---|
| **0002_treadmill_slow** | **L 67% / R 64%** | 8/14% | 81-92% | 29/37° |
| 0000_treadmill_norm | L 71% / R 22% | 18/33% | 71-77% | 27/39° |
| normal_walk 系（0005/0007/0008） | **0%** | ~100% | 2-37% | 15-31° |
| jog 系（0003/0009） | 0% | 100%（跑步正常） | 4-37% | 24-25° |

v53 策略（walk10）：落足 **跟先 14%/32% + 平先 86%/68% + 趾先 0**；蹬离 **toe-off 100%**（已达标，动力学涌现）。
v54 后补测（同工具）：v54 跟先 23%/35%；soup534_40 walk10 跟先 14%/41%、walk05 6-12%——**平先主导在全部候选基座一致**，蹬离 walk10 ~100% 保持（walk05 低速下噪声较大）。

**诊断结论**：
1. **数据是"部分有"**：0002_treadmill_slow 是唯一跟先+直膝双优片段（~65% 跟先），但不纯（65%≠100%）；normal_walk 系反而 100% 趾先（名字最像标准行走实为拖脚走）。**不需要重做重定向**——FK 实测证明重定向保留了源动作的脚部时序特征；需要的是片段权重调整（见 §5）。
2. **策略已是半 heel-toe**：全掌落地（0 趾先）+ 滚动 + 100% toe-off 蹬离。**缺的只有触地瞬间的跟先**。
3. **元凶代码已定位**：`stance_sole_flat_walk`（v27 引入治"踮脚走"）在 cmd ≤1.5 m/s 全 stance 罚非平足——把 heel-strike 触地相和 heel-off 蹬离相一起压平了。改造它比新增奖励更根本。
4. 蹬离相（toe-off）已 100% 达标，不需要新增奖励，只需在改造平足罚时别误伤。

## 4. 奖励设计草案（先读码算数再定稿）

### 4.1 knee_extension（直膝主杠杆）

```python
# stance 指示（双足任一/各自在支撑）× exp 内核，只在屈曲 >15° 时产生梯度
r = stance_i * exp(-max(0, θ_knee_i - 0.26) / σ),  σ ≈ 0.17 rad (10°)
# θ_knee: 膝角，0=全伸；0.26 rad = 15° 目标线
```
- **数值定标**：当前 θ_mid=36° → r=0.12；达标 15° → r=1.0。w 起步 **0.15**（与幅度先验 0.08 同量级、略高——膝是双侧四关节耦合项）。做 3 点剂量曲线（0.1/0.15/0.25），复用 v52-54 方法论。
- 参考文献锚：UCL Gait-Conditioned RL（arXiv 2505.20619）Straight-Knee 项 w=+0.1 同型。
- **风险预告**：直膝与 push 鲁棒性是真实权衡（v42-48 的 51-52/60 部分靠蹲步缓冲）。鲁棒门从 51 掉到 48 是预算内代价；跌破 48 视为过量，减剂量。

### 4.2 heel_first（跟先触地）

实现走**几何法**（Isaac 侧无逐球接触传感——4 球同属 ankle_roll_link，body 级 contact_forces 分不出跟/趾；但有 `body_pos_w`/`body_quat_w`，与 sim2sim 的 sole_xyz 完全同构）：

```python
# 跟/趾两端球世界坐标（foot frame: toe = +z_local, sole = -y_local, 与 stance_sole_flat_walk 同约定）
z_toe, z_heel = world_z(球偏移 ±0.07m 两端)
触地 = z < 5mm（含球半径）
# 事件窗：本控制步处于该足触地后首帧（上升沿检测）
落足分类：跟侧已触且趾侧未触 → +1.0（跟先）
          同帧触地 → +0.3（平先，过渡期给分）
          趾侧先 → 0（G3 罚另行管）
r = w_hf * 事件分
```
- w 起步 **0.15**。量化：每步 ~0.5s、22 次落足/12s，全跟先时平均 ~+0.3/step @w=0.15，与幅度先验同量级。
- 与 120fps 参考 FK 的跟/趾判定窗口（`diag_heeltoe.py` CONTACT_Z=10mm）保持一致或更严。

### 4.3 stance_sole_flat_walk 改造（元凶解除，必做）

现版在 cmd ≤1.5 m/s 全 stance 罚非平足 → 压掉 heel-strike 与 heel-off。改为**分相**：
- 触地段（触地后 ~100ms / 5 控制步）：**豁免**（或反向给 4.2 的跟先分）
- foot-flat 段：保持平足罚（治踮脚走的原始功能不丢）
- 蹬离段（趾侧仍触、跟侧已离）：**豁免**（toe-off 100% 是资产，别误伤）
- 分相判据用与 4.2 相同的跟/趾几何（跟离趾在 = 蹬离相；同触 = flat 相）

### 4.4 数据权重（数据侧唯一动作）

`motion_data_weights`：**0002_treadmill_slow 2.0 → 4.0**（唯一跟先+直膝双优片段，其镜像同步加权）。normal_walk 系（趾先）维持 2.0 不动——趾先票源降权会伤害 disc 对"不拖着走"的判别，且 H1 奖励已直接覆盖落足。jog 系不动（趾先在跑步是正确的）。

**明确不做**：重做重定向（实测证明参考已含直膝与跟先，无需接触感知重定向）；AMASS 外部数据集引入（Fukuchi/TotalCapture 力板时序留作后续人类参数标定参考，本 arc 不需要）。

**方法论约束（全部来自本 arc 付费教训）**：
1. **单变量**：每轮只动一个杠杆，A/B 对照同基座同剂量。
2. **剂量-响应曲线**：新奖励至少 3 点剂量再定发布值（v52 一点 0.3 直接过量 2.7×）。
3. **短探针结论必须长程复证**：300-iter probe 有"守卫惯性"假阳性前科（v41 证伪了 probe 的 2/3 结论），1000-iter 终验才算数。
4. **奖励四原则**：数值定标、梯度可传、唯一方向、精简不堆叠（sigma 覆盖初始策略所在区间，参考 sigma=0.08 梯度消失事故）。
5. **eval 三层交叉验证**：源（AMASS FK）→ 参考（pkl FK）→ sim2sim（npz）同指标测量，禁止单源（v28b/v32b 教训，已固化经验条目）。
6. **警惕特征耦合**（v53/v54 新增教训）：幅度先验与步态相位反向耦合（0.08 时 walk05 phase 丢、0.06 时恢复但幅度回落 40%）——knee_extension 与 push 鲁棒、heel_first 与平足罚同样存在潜在耦合，故每轮必须全指标复测而非只看主判据。
