# F1w（F1 29DOF weilai）AMP 跑步训练数据量评估

日期：2026-11-10 ｜ 任务：F1 weilai 跑步 AMP 训练 + sim2sim
外部文献调研报告：`.meta-agent/research/subtask-fa33cabd/report.md`（11 源，含 AMP 原论文、
IsaacGymEnvs、G1 29DOF walk/run、HumanMimic、ExBody、ASE、Multi-Gait 等）

## 结论（数据量需求）

**跑步演示库：8–14 条跑步片段（源+镜像 16–28 体），单条 ≥10 s、总时长 ≥3 min，
速度连续覆盖 1.2 → 3.0+ m/s（慢跑 1.2–2.0 / 中速跑 2.0–2.8 / 快跑 2.8–3.5），
另配 6–10 条行走片段（0.4–1.3 m/s）锚定低速域与步态过渡。**

要点：AMP 跑步先验**数据便宜**——单条 15–30 s 跑步片段即可驱动 3–5 m/s；规模不是驱动因素，
**速度覆盖与风格同质性才是**；演示速度谱必须覆盖并略超命令速度带上沿，否则判别器在高速命令下
奖励错误步态（快速走）。风格权重需保守（λ_amp≈0.5；过强压制爆发步态）。

### 仓库内依据（X1 18 轮弧线）

1. **量级实证**：v16/v17 14 条 AMASS 走路训练成功；v72 36 源（0.66–1.27 m/s 连续覆盖）+
   2D 速度分桶权重（PRIME 1.2 / MID 0.7 / FAST 0.5）J 门 + 严格门双 PASS。跑步域无理由需要更多。
2. **风格质心机制（关键约束）**：v86b2 分析证实策略速度被演示速度质心钉住——cmd-1.0 流风格质心
   ~0.99 m/s → 全杠杆天花板 0.895 m/s。**F1w 跑步演示库的加权速度质心必须落在目标命令带内**，
   否则重演 X1 速度天花板。
3. **f08 快族实践**：CMU 08_x 慢跑 6 条（1.1–1.33 m/s，2.3–2.9 s/条）重定向过门（G2 弃 2 条
   支撑俯仰不对称）；短片段可用但每条 <3 s 时判别器窗口内风格信息稀薄（X1 v90 PRIMEF08 未能
   突破速度，部分归因于此）→ 跑步片段**优先选 ≥10 s 的连续试验**。
4. **镜像成对**：J 门要求源+镜像成对（S 组）；跑步对称性更重要（步态不对称在跑步下被放大）。
5. **质量门不可降**：check_retarget A–G 硬门 + J 门步态质量门全量适用；跑步新增门
   （腾空相存在性、触地节律、速度谱）按契约预注册（见 RETARGET_ACCEPTANCE 增补节）。
